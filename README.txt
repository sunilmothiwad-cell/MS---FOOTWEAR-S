CURRENT LIMITATIONS — PLEASE READ
This is a working front-end starter, not yet a full production ecommerce backend.
Products, cart and stock are stored only in the current browser/device. Orders are sent to WhatsApp; they are not saved to a cloud admin dashboard. Demo admin PIN is not secure. There is no customer login, multi-device stock sync, payment gateway verification, automatic shipping integration, GST invoice engine, or server-side database yet.

To launch a real multi-customer store, the next phase needs a secure backend/database, authentication, server-side order and inventory validation, backups, privacy/terms/returns pages, payment provider onboarding (e.g. Razorpay/Cashfree), and shipping integration. Payment gateway account approval and KYC may be required. Hosting can start on free tiers, but domain, transaction fees, SMS, shipping and some services may cost money.
